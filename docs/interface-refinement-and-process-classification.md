# 进程分类、清理判断与界面

界面把判断直接放进列表：分类计数互斥且覆盖全部进程，原因就近展示，操作集中在工具栏。分段切换器按内容宽度显示，超出可用宽度时滚动，支持方向键、Home / End 和键盘焦点。

## 自动进程判断

| 分类 | 判断与处理 |
| --- | --- |
| 建议清理 | 已观察到父链退出，明确为构建或测试任务，并有至少 5 分钟持续空闲的 CPU、内存及可读 I/O 证据；执行前重新检查身份与活动 |
| 仍在工作 | 观测到 CPU、内存或 I/O 活动，保留运行 |
| 空闲保留 | 正常父链中的已知任务、应用组件，或明确的常驻服务、监听任务 |
| 继续观察 | 疑似遗留构建 / 测试，但连续观察时间或可读 I/O 证据不足，由后台继续采样 |
| 需进一步复核 | 用途不明、资源异常、状态特殊，或仍有需要运行的子进程；原因直接展示 |
| 已排除 | AgentLens 自身启动链，禁止停止和批量选择，后端独立保护 |

旧界面只统计建议、活动和复核，漏掉正常待命组件，容易把所有非活动任务都理解成待人工处理。现在六类分别计数，未知类别值也会安全回退到复核，不会从统计中消失。

另一个实际缺陷是把累计读写 `0` 当成“读不到”。真正没有发生磁盘 I/O 的任务因此永远无法建立空闲证据。现在区分系统读取成功与失败：成功的 `0 → 0` 可以参与连续观察，读取失败、时间中断、活动恢复或 PID 复用会重置空闲窗口。

Agent、编辑器、渲染器、MCP、开发服务和 watch 任务属于可合理常驻的组件，低 CPU 或父链退出不能证明其无用。未知任务也不会为了减少复核数字而改标为正常。建议数量取决于现场证据，零建议可能是正确结果。

重新检测调用独立进程采样。批量建议停止使用专门命令，按子进程优先核验 PID + 启动时间、归属、保护链和当前建议条件；拒绝后不回退为普通停止。

## 为什么清理候选可能为零

旧缓存存在不代表当前可安全清理。默认要求规则命中、超过保留期、至少两次间隔 10 秒的稳定观测、所属 Agent 未运行，以及可核验的普通单硬链接文件。

本轮在真实索引中确认：原有大量旧文件因 Codex / Cursor 正在运行而保留；同时发现更新器下载的应用安装资源被广义缓存路径误分类。已增加 `.app`、`.framework`、`.bundle` 和 Sparkle 载荷保护，避免未来退出应用时误删安装资源。Lumo 的结构化 JSONL 日志也改为日志，凭据、数据库和源码仍优先保护。

清理页的空状态直接解释运行中保护、等待稳定、筛选无结果或保留策略。Agent 活动集合改变会自动请求重新扫描，减少用户退出应用后还需手动排查的情况。文件仍经过预览和执行前复核，不降低保护来制造候选。

## 界面做法

- 总览、Agent、存储、会话、进程、清理、活动、设置沿用统一网格与间距，减少重复说明和辅助标签。
- 首次扫描以镜头、轨道和资源信号展示真实阶段；暂停时冻结动态效果，系统减少动态效果偏好下仍能阅读进度。
- 图标使用统一视口和网格居中；列表工具栏按钮采用一致高度；切换器按内容宽度显示。
- Header 与系统菜单栏资源面板点击打开，移开鼠标后保持可交互；再次点击、Escape 或外部点击关闭。
- 通知悬浮显示，后台扫描保持布局和阅读位置。长列表分页，更新提示由用户决定何时查看。

37 项 Rust、13 项 Vitest、26 项 Playwright 测试通过。覆盖零 I/O、身份复用、父子依赖、安装资源保护、JSONL 日志、54 进程完整分类、空列表重新检测、排除项禁用操作、扫描暂停、语言主题、弹层与批量确认。

macOS 原生界面已完成 Lumo 规则接入和三个目录索引。未对真实用户文件执行清理，未停止真实用户进程。测试与本地核验中间产物保存在忽略的 `artifacts/`，公开截图使用标识清楚的预览数据。
