# 接入自定义 Agent 与桌面应用

没有 CLI 的应用也能接入。AgentLens 识别的是**可执行文件和可观察的进程树**，目录统计则由显式绑定的用途决定。

## 以 Lumo 为例

在「Agent 管理 → 接管 Agent」选择运行中的 Lumo，或切换到「自定义识别规则」填写：

| 字段 | 值 |
| --- | --- |
| 名称 | Lumo |
| 可执行文件 | `/Applications/Lumo.app/Contents/MacOS/lumo` |
| 脚本或模块入口 | 留空 |
| 保存识别规则 | 开启，重启后继续识别 |

`.app` 文件夹本身不是可执行文件。应用更新或安装位置变化后，应检查实际可执行文件路径。Node、Python 等共享运行时还需精确脚本路径或 `module:包名`，避免把全部同类运行时误归给一个 Agent。

按真实语义绑定目录，逐个选择用途，然后预览进程、内存和目录范围，确认后保存：

| Lumo 目录示例 | 用途 | 行为 |
| --- | --- | --- |
| `~/.lumo/chats` | 项目 · 仅监测 | 统计大小，保护聊天文件 |
| `~/.lumo/attachments` | 项目 · 仅监测 | 统计附件，保持保护 |
| `~/.lumo/logs` | 日志 | 按日志保留期和运行状态评估，支持 JSONL 日志 |

本轮已通过 macOS 原生界面完成以上接入，保存精确识别规则、识别到运行中的 Lumo 主进程，并对三个目录建立索引。进程数量和占用会随使用变化，示例路径也可能随应用版本变化。

不需要绑定整个 `~/.lumo`。整目录可能混有凭据、数据库、工作区和已被其他规则识别的子目录；重叠目录会被拒绝。新增缓存目录前应确认其内容可再生成，不能仅凭目录较大就标记为缓存。

## 识别范围

接入后自动跟踪可核验的子进程。已经由内置规则识别的独立 Agent 保持原有归属；系统代管、无法追溯到应用父链的 WebKit 进程可能不在范围内。

目录绑定表示统计关联，不能证明某个进程写入了每个文件。自定义接入也不会自动解析未知的会话格式。取消接管只移除规则与关联，不停止应用、不删除文件。
