# 通用 Agent 接管

状态：第一阶段已实现并接入客户端（2026-11-19）。技术栈保持 Tauri 2 + Vue 3 + Rust + SQLite。

## 已实现的使用流程

Agent 页面右上角提供“接管 Agent”：

1. 搜索当前用户的运行进程，显示 PID、程序/脚本路径、RSS、CPU 和既有归属；也可直接填写精确识别规则。
2. 设置名称与颜色。选中进程后，可仅接管本次运行，也可保存规则，在未来启动相同程序和入口时自动识别。
3. 按需绑定目录，指定项目、缓存、日志或临时用途。
4. 预览进程树、合计 RSS 和目录，再确认。提交时重新读取进程，检查身份、规则冲突与目录重叠。
5. 自定义 Agent 加入现有资源统计、存储增长、历史、活动、菜单栏、进程说明和批量停止流程。Agent 页面可解除接管。

接管不执行第三方代码，不启动 Agent，也不在接管时终止进程或清理文件。

## 注册表与归属

`src-tauri/src/adoption.rs` 定义 `AgentDefinition`、`ProcessRule`、`AgentBinding`、目录请求和预览数据。内置定义保留原有 ID，自定义 ID 为 `custom-<UUID>`。

注册表和绑定目录一起写入 SQLite 配置事务；快照提供统一的 `agentDefinitions`。所有资源汇总、基线、增长事件、目录 Agent 校验、清理排除校验、执行前进程识别与前端元数据都使用动态定义。前端保留已解除定义的名称与颜色，以便解释历史记录。

识别顺序为内置身份、用户确认的当前进程绑定、保存的精确规则，再扩展父子关系。规则/进程树与现有 Agent 冲突时拒绝接管，避免一个进程重复归属。

- **临时接管**：核对当前用户、PID、启动时间、可执行文件路径，绑定仅存在于内存；AgentLens 重启后不会凭旧 PID 恢复。
- **保存规则**：精确匹配可执行文件路径。Node、Python、Shell 等共用运行时还必须匹配具体脚本入口，Python 支持 `module:package.name`。自动提取器只读取入口，不把其余参数或令牌发送到前端。复杂 `-c`、`-e`、未知包装器调用可采用临时接管。
- **子进程与遗留进程**：跟踪同一用户、启动顺序有效的父链。已观测后代在父进程退出后，继续通过 PID 与启动时间核验，并显示遗留状态。内部辅助进程、WebView 和 AgentLens 自身不会被接管；接管候选还排除启动祖先。
- **进程操作**：沿用既有逐项停止和批量确认。执行前使用同一注册表与绑定重新识别，并保留当前用户、进程身份和启动祖先保护。

路径规则使用完整路径精确匹配，安装位置改变后需要重新配置。该阶段没有可执行文件内容哈希或签名身份校验。

## 目录与清理

目录必须真实存在、位于用户主目录的具体子目录内，且不能与已有监测根或本次其他绑定重叠。本阶段以拒绝重叠的方式避免重复计数，尚未实现共享目录的多 Agent 关联。

| 指定用途 | 行为 |
| --- | --- |
| 项目 | 统计空间及变化，默认保护，不按普通缓存删除 |
| 缓存 | 使用现有缓存启用开关与保留天数 |
| 日志 | 使用现有日志启用开关与保留天数 |
| 临时文件 | 使用现有临时文件启用开关与保留小时数 |

自定义用途不绕过源码、配置、凭据、数据库、未知 JSONL 会话历史、排除路径、排除 Agent、最小文件体积、稳定观测、活跃进程、路径/文件身份及系统垃圾桶复核。已绑定目录会进入后台扫描；目录绑定表示用户指定的归属，不能证明每个文件的实际创建进程。

解除接管只停用规则、移除运行时绑定与该 Agent 的监测根，并清除过期清理计划及索引范围。它不删除文件、不停止进程；历史定义保留。

## 后续能力与精度边界

本阶段可接入未预置工具的本地进程树和明确绑定的目录。不会仅凭所有 Node/Python、浏览器或编辑器进程自动断言其属于 AI Agent。浏览器内、远端或云端 Agent 需要对应上下文或采集端。

会话关联继续按现有可读元数据展示；普通文件 watcher 和目录增长不能还原历史文件创建进程，也不能保证把任意客户端文件精确对应到会话。

下一阶段可以增加受控启动入口：生成本地 run ID，记录启动参数数组、工作目录、进程身份与目录基线，再通过适配器报告关联内部 session ID。若需精确到某个 PID 写入某个文件，需要额外的平台审计后端；macOS Endpoint Security、Windows ETW 与 Linux eBPF/fanotify 的权限与能力不同，不能宣称三端具备相同精度。
